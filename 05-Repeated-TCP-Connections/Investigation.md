# Repeated TCP Connection Investigation

## Objective
Investigate repeated TCP connection attempts and identify connection failure patterns using Wireshark.

## Tools Used
- Wireshark 4.6.9
- Windows PowerShell
- Npcap Loopback Capture Adapter

## Lab Environment
- Source IP: 127.0.0.1
- Destination IP: 127.0.0.1
- Destination Port: 65000
- Protocol: TCP
- Environment: Authorized localhost simulation

## Traffic Simulation
The following PowerShell command generated repeated TCP connection attempts:

```powershell
1..10 | ForEach-Object {
    Test-NetConnection 127.0.0.1 -Port 65000 -InformationLevel Quiet -WarningAction SilentlyContinue
    Start-Sleep -Seconds 3
}
```

The PowerShell output showed unsuccessful TCP connections (False).

## Wireshark Display Filters

```text
ip.addr == 127.0.0.1 && tcp.port == 65000

tcp.dstport == 65000 && tcp.flags.syn == 1 && tcp.flags.ack == 0
```

## Packet Analysis

| Packet | Time (seconds) | Observation |
|---|---|---|
| 54030 | 983.8995 | SYN to port 65000 |
| 54031 | 983.8995 | RST, ACK response |
| 54032 | 984.4074 | SYN retry |
| 54033 | 984.4075 | RST, ACK response |
| 54050 | 984.9079 | SYN retry |
| 54051 | 984.9080 | RST, ACK response |
| 54296 | 989.1441 | New SYN using source port 58983 |
| 54297 | 989.1442 | RST, ACK response |

## Observations
- Repeated TCP SYN packets targeted localhost port 65000.
- The destination rejected the connection attempts with RST, ACK responses.
- Multiple source-port groups were observed.
- Some attempts were approximately 0.5 seconds apart, consistent with connection retry behavior.
- The traffic did not establish a successful application connection.

## SOC Investigation Findings
Repeated failed connection attempts may be generated by legitimate applications, automated scripts, connectivity checks, or potentially malicious software.

Periodic network communications can be investigated as possible command-and-control indicators, but timing patterns alone cannot confirm malicious activity.

This experiment did not demonstrate actual malware communication or external C2 beaconing.

## SOC Conclusion
The repeated TCP connections were intentionally generated using PowerShell in an authorized local lab.

Classification: Benign Positive — Authorized Simulation.

No malicious activity was identified.
